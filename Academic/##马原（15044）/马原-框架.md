```shell
#🚗商品经济和价值规律
# 劳动生产率
劳动生产率是劳动者生产某种使用价值的效率，通常可以用单位时间内生产的产品数量来表示。
- 劳动强度：单位时间内劳动者的劳动紧张程度或劳动力耗费程度。
# 劳动生产率与单位商品价值量的关系
在其他条件不变的情况下，劳动生产率越高，单位商品的价值量越小；劳动生产率越低，单位商品的价值量越大。
# 为什么劳动生产率提高，价值总量通常不变
马克思主义政治经济学区分的是单位商品的价值量和一定时间内新创造的价值总量。
- 劳动生产率提高(单位商品价值量下降)
- 社会必要劳动时间增加(单位商品价值量上升)
- 劳动时间延长(在其他条件相同的情况下，创造的价值总量增加)
```

```shell
#🚗资本主义经济制度的本质
商品经济可以存在于不同社会形态，而资本主义经济制度具有特定的历史条件和阶级关系。
- 商品经济： 以交换为目的的生产经济形式。
- 资本主义经济制度： 以资本主义生产关系为基础的经济制度。
# 资本主义经济制度产生的基础
资本主义经济制度的形成，与劳动者和生产资料相分离、劳动力成为商品等条件密切相关。
# 劳动力
劳动力: 是人的劳动能力，即人的体力和脑力的总和。
劳动： 劳动力在生产过程中的实际运用。
# 劳动力成为商品的两个基本条件
- 劳动者具有人身自由
- 劳动者没有生产资料，也没有足够的生活资料，必须通过出卖劳动力来维持生活。
# 劳动力商品的价值与使用价值
劳动力的使用价值能够创造价值，而且可能创造出超过劳动力自身价值的价值。
- 劳动力商品的价值(生活资料价值/劳动者教育培训)
- 劳动力商品的使用价值(劳动者实际运用劳动力进行劳动，能够创造价值)
# 为什么劳动力能够成为商品
- 资本家需要劳动者的劳动来生产商品、创造价值
- 资本家购买的并不是劳动者这个人，而是劳动者在一定时间内提供的劳动力的使用权。
- 劳动力成为商品，意味着劳动者通过出卖劳动力获得生活资料。
# 劳动力商品的价值
劳动力商品的价值，是由生产和再生产劳动力所必需的生活资料的价值决定的。
- 维持劳动者本人生活所必需的生活资料
- 维持劳动者家庭及劳动力延续所必需的生活资料
- 教育和训练所支出的费用
工资: 在资本主义制度下，劳动力价值或价格的货币表现形式；实际工资还可能受到供求关系、劳资力量对比等因素影响。
# 劳动力商品的使用价值
一般商品的使用价值，是它能够满足某种需要的有用性。
- 劳动力的使用能够创造价值，而且能够创造出超过劳动力自身价值的价值。
- 资本家购买劳动力时支付的价值，与劳动力在使用过程中能够创造的新价值，并不是同一个量。
	劳动力价值
	剩余价值(超过劳动力自身价值)
# 在假设等价交换的情况下，资本主义生产仍然可能产生剩余价值
- 资本家按照劳动力的价值或价格购买劳动力。
- 劳动者在生产过程中创造的新价值可能超过劳动力自身的价值。
- 超过劳动力自身价值的部分形成剩余价值，并被资本家占有。
#🚗资本主义生产过程的二重性
资本主义生产过程是劳动过程和价值增殖过程的统一。
- 劳动过程(劳动者/劳动/使用价值)
- 价值增殖过程(劳动力/超过自身价值)
# 必要劳动时间与剩余劳动时间
- 必要劳动时间：再生产劳动力价值所需要的劳动时间。
- 剩余劳动时间：超过必要劳动时间、为资本家生产剩余价值的劳动时间。
# 绝对剩余价值与相对剩余价值
- 绝对剩余价值: 通过延长工作日，或者在必要劳动时间不变时增加剩余劳动时间，来增加剩余价值。
- 相对剩余价值: 在工作日长度不变的条件下，通过提高社会劳动生产率、降低劳动力价值，从而缩短必要劳动时间、相应增加剩余劳动时间。
#🚗资本的划分：不变资本与可变资本
- 不变资本(c): 用于购买生产资料的资本
	在生产过程中，生产资料的价值转移到新产品中，本身不创造新的价值。
- 可变资本(v): 用于购买劳动力的资本
	劳动力在生产过程中创造新价值，而新价值可以超过可变资本本身的价值。
- 剩余价值(m)的源泉是雇佣劳动者的剩余劳动，而不是机器本身。
# 资本的价值构成公式
- 商品价值: W = c + v + m
- 剩余价值率: m'= m/v * 100%
	m'= 剩余劳动时间/必要劳动时间 * 100%
#🚗剩余价值生产的两种基本方法
- 绝对剩余价值的生产
	延长工作日、必要劳动时间不变、剩余劳动时间增加。
- 相对剩余价值的生产
	缩短必要劳动时间,社会劳动生产率提高、劳动力价值降低
# 超额剩余价值
- 超额剩余价值，是指个别资本家由于提高企业劳动生产率，使商品的个别价值低于社会价值而获得的额外剩余价值。
- 相对剩余价值： 社会劳动生产率提高，使劳动力价值下降，必要劳动时间缩短。
- 个别生产率提高，可能获得超额剩余价值；社会生产率提高，可能形成相对剩余价值。
#🚗资本积累
资本积累，是指把剩余价值转化为资本，使扩大再生产得以进行。
- 简单再生产： 生产规模不变，剩余价值主要用于资本家个人消费。
- 扩大再生产： 把部分剩余价值转化为追加资本，扩大生产规模。
- 资本积累： 剩余价值转化为资本的过程，是扩大再生产的重要基础。
# 影响资本积累的因素
- 对劳动力的剥削程度(剩余价值率提高)
- 社会劳动生产率水平(劳动生产率提高)
- 所用资本和所费资本的差额(固定资本磨损)
- 预付资本的大小
# 资本有机构成
资本有机构成是由资本技术构成决定并反映技术构成变化的资本价值构成，通常用c:v表示
- 资本的技术构成(生产资料与劳动力之间的比例关系)
- 资本的价值构成(资本在价值上分为不变资本与可变资本的比例关系)
资本有机构成提高不等于任何情况下就业人数都会绝对减少；就业还会受到生产规模扩张、产业变化等因素影响
#🚗资本主义的基本矛盾
生产社会化与生产资料资本主义私人占有之间的矛盾。
- 生产社会化(社会化劳动)
- 生产资料资本主义私人占有
# 经济危机的可能性与根源
资本主义经济危机通常表现为商品大量滞销、生产下降、企业倒闭、失业增加等。
- 经济危机的根本原因：资本主义基本矛盾。
- 经济危机的直接原因: 常涉及生产与消费的矛盾、相对过剩等具体机制
#🚗资本循环
资本循环是指资本依次经过购买、生产和销售三个阶段，采取不同职能形式，实现价值增殖并回到原来出发点的运动过程。
- G: 货币资本
- W：商品，包括生产资料和劳动力。
- P: 生产过程
- W': 包含剩余价值的商品
- G': 收回的增殖后的货币资本
# 资本循环的三个阶段
- 购买阶段(货币资本/生产准备条件)
- 生产阶段(生产资料与劳动力/新商品)
- 销售阶段(新商品/增殖后的货币)
只有生产阶段才直接生产剩余价值；购买阶段为生产准备条件，销售阶段实现商品价值和剩余价值。
# 资本的三种职能形式
- 货币资本(购买生产资料和劳动力)
- 生产资本(生产商品和剩余价值)
- 商品资本(出售商品，实现价值增殖)
资本的三种职能形式不是三种互不相关的资本，而是同一资本在循环中采取的不同形式。
# 资本周转
资本周转速度影响资本在一定时期内能够完成多少次循环，也会影响预付资本的利用效率。
- 资本周转时间
	生产时间：资本处于生产领域的时间。
	流通时间：资本处于购买和销售等流通领域的时间。
- 周转时间越短，资本周转速度越快；周转时间越长，资本周转速度越慢。
#🚗固定资本与流动资本
- 固定资本
	以厂房、机器设备等劳动资料
	价值逐步转移
	多个生产周期发挥作用
- 流动资本
	一个生产周期全部转移
	劳动力使用形成新价值的生产资本
- 固定资本与流动资本的划分依据，是生产资本价值周转方式的不同。
# 不变资本、可变资本与固定资本、流动资本不是同一组分类
- 不变资本与可变资本：按资本在价值增殖中的不同作用划分。
- 固定资本与流动资本：按生产资本价值转移和周转方式划分。
# 预付资本的总周转
总周转次数 = 一年内各部分资本周转的价值总额/预付资本总额
#🚗社会资本再生产
社会总资本，是指相互联系、相互依存的个别资本的总和。
# 社会生产的两大部类
- 第Ⅰ部类：生产生产资料的部门
	需要用于扩大和维持社会生产
- 第Ⅱ部类：生产消费资料的部门
	需要满足劳动者及其他社会成员的生活消费。
- 两大部类的产品必须通过一定比例的交换，才能实现社会再生产的正常进行。
# 简单再生产与扩大再生产
- 简单再生产：生产规模保持不变，生产出来的剩余价值主要用于资本家个人消费。
- 扩大再生产：生产规模扩大，需要把一部分剩余价值转化为追加资本。
社会资本再生产理论研究的重点，是社会总产品如何在各部门之间实现价值补偿和实物补偿，从而使再生产能够继续进行。
#🚗社会资本再生产的实现条件
# 社会总产品与两大部类(经济用途)
社会总产品是社会各物质生产部门在一定时期内生产出来的全部物质产品。
- 第Ⅰ部类：生产生产资料
- 第Ⅱ部类：生产消费资料
# 简单再生产的基本实现条件
v: 可变资本
m: 剩余价值
c: 不变资本
Ⅰ(v+m)=Ⅱc
# 扩大再生产(生产规模不断扩大)
扩大再生产是指将一部分剩余价值转化为追加资本，使下一轮生产规模扩大。
扩大再生产不仅要补偿已经消耗的生产资料和劳动力，还要为追加资本提供相应的生产资料与消费资料。
社会总资本再生产能否顺利进行，取决于各部门之间是否保持必要的比例关系。生产出来的产品在实物上合适、在价值上能够实现，社会再生产才有条件继续进行。
# 两种补偿：价值补偿与实物补偿
- 价值补偿：商品通过销售实现价值，使资本家能够收回预付资本，并实现剩余价值。
- 实物补偿：生产过程中消耗的生产资料和消费资料，必须在实物形态上得到相应补充。
- 社会资本再生产需要同时考虑价值补偿和实物补偿，而不是只看产品有没有生产出来。
```
