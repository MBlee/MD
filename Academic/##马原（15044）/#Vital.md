```shell
#🚗对立统一规律(矛盾规律)
# 统一/斗争性
- 矛盾的同一性(指矛盾双方相互依存、相互贯通的性质和趋势。)
- 矛盾的斗争性(指矛盾双方相互排斥、相互分离的性质和趋势。)
- 矛盾的同一性和斗争性是辩证统一的。同一性不能脱离斗争性而存在，斗争性也不能脱离同一性而存在。矛盾双方既相互依存，又相互排斥，共同推动事物的发展。
# 普遍/特殊
- 矛盾的普遍性(是指矛盾存在于一切事物的发展过程中，并贯穿每一事物发展过程的始终。)
- 矛盾的特殊性(是指不同事物的矛盾、同一事物不同发展阶段的矛盾，以及构成事物的不同矛盾和矛盾双方各有其特点。)
  + 不同事物的矛盾各有特点
  + 同一事物在不同发展阶段的矛盾各有特点
  + 同一事物中的不同矛盾，以及同一矛盾的双方，各有特点
- 矛盾的普遍性与特殊性相互区别。 
普遍性是共性，特殊性是个性，二者不能完全等同。
矛盾的普遍性与特殊性相互联结。 
普遍性寓于特殊性之中，并通过特殊性表现出来；特殊性也离不开普遍性。
矛盾的普遍性与特殊性在一定条件下可以相互转化。
# 普遍/特殊方法论意义
坚持具体问题具体分析。(分析和解决问题时，要从具体的时间、地点、条件出发，分析事物矛盾的特殊性，采取适合实际情况的方法。)
# 主要矛盾与次要矛盾
在复杂事物的发展过程中，存在着多种矛盾，
其中处于支配地位、对事物发展起决定作用的矛盾，就是主要矛盾。
其他处于从属地位、对事物发展不起决定作用的矛盾，是次要矛盾。
主要矛盾和次要矛盾的地位不是固定不变的，在一定条件下可以相互转化。
# 主要矛盾的意义
分析复杂事物时，要善于抓住主要矛盾。
方法论是：坚持重点论，着重把握主要矛盾。
但这不等于只管主要矛盾、完全不管其他矛盾。次要矛盾也会影响事物的发展。
# 矛盾的主要方面与次要方面
在一个矛盾的两个方面中，
处于支配地位、起主导作用的一方，就是矛盾的主要方面。
另一方则是矛盾的次要方面。
事物的性质主要是由取得支配地位的矛盾的主要方面决定的。
# 矛盾主要方面的意义
分析一个事物时，要分清矛盾双方谁处于主导地位，不能因为存在某些问题，就否定事物的整体性质。
方法论是：坚持两点论，全面分析矛盾双方，同时抓住主要方面。
# 两点论与重点论的统一
两点论：既看到主要矛盾，也看到次要矛盾；既看到矛盾的主要方面，也看到次要方面。
重点论：着重把握主要矛盾和矛盾的主要方面。
两者统一起来，就是：全面分析问题，同时抓住重点和主流。
```

```shell
#🚗否定之否定规律
辩证否定是事物的自我否定，是事物发展的环节，也是新旧事物联系的环节。
自我否定：事物的发展变化，源于其内部矛盾运动，不是简单地由外部力量任意决定。
发展的环节：通过否定，旧事物才能向新事物发展。
联系的环节：新事物不是凭空出现的，而是在旧事物的基础上产生。
# 辩证否定的两个重要特点
- 否定是发展的环节
	旧事物被新事物取代，是事物发展过程中的重要环节。
- 否定是联系的环节
	新事物是在旧事物的基础上产生的，因此会保留旧事物中合理的因素。
- 辩证否定的实质是“扬弃”。
	扬：保留旧事物中积极、合理的因素。
	弃：克服旧事物中过时、消极的因素。
事物的发展不是简单地直线前进，而是经历两次否定、三个阶段，表现为螺旋式上升或波浪式前进。
# 否定之否定规律的方法论意义
- 要对事物的发展前途充满信心。
	新事物具有符合客观规律、具有强大生命力和远大发展前途等特点。
- 要充分认识事物发展的曲折性。
	事物发展不是一帆风顺的，可能经历反复、挫折，但不能因此否定其发展的总体趋势。
```

```shell
#🚗三大规律
对立统一规律是唯物辩证法的实质和核心。

#🚗唯物辩证法的基本范畴
# 1. 原因与结果
原因：引起某种现象的现象。
结果：由原因引起的现象。
二者相互联系，在一定条件下还可以相互转化。
方法论：分析问题时要追究原因，也要关注行为可能带来的结果。
# 2. 必然性与偶然性
必然性：事物发展过程中确定不移的趋势。
偶然性：事物发展过程中不确定的趋势和表现。
必然性和偶然性相互联系，不能割裂。
偶然性不是完全没有原因，必然性也不意味着每个具体结果都能被简单预测。
# 3. 可能性与现实性
可能性：事物发展中潜在的趋势。
现实性：已经产生、实际存在的事物或状态。
可能性转化为现实性需要一定条件。
方法论：既要看到可能性，也要创造条件促使积极可能性转化为现实。
# 4. 内容与形式
内容：构成事物的一切要素及其内在联系。
形式：内容诸要素相互结合的结构和表现方式。
内容与形式相互依存，内容决定形式，形式对内容具有反作用。
# 5. 本质与现象
本质：事物的根本性质，以及组成事物的基本要素之间的内在联系。
现象：事物的外部联系和表面特征。
本质通过现象表现出来，现象是认识本质的向导，但现象不一定直接、完整地反映本质。
方法论：不能停留在表面现象，要通过分析研究把握事物本质。
```

```shell
#🚗唯物辩证法是认识世界和改造世界的根本方法
唯物辩证法不只是解释事物怎样发展，还指导我们怎样认识问题、分析问题和解决问题。
# 1. 归纳与演绎
归纳：从个别事实中概括出一般规律。
演绎：从一般原理推导出个别结论。
归纳由个别到一般，演绎由一般到个别。
# 2. 分析与综合
分析：把事物分解为不同部分、方面，分别研究。
综合：把对各部分的认识结合起来，形成对整体的认识。
分析是分开看，综合是合起来看。
# 3. 抽象与具体
感性具体：通过感官直接接触到的完整、具体事物。
思维抽象：从具体事物中抽取某些共同的、本质的属性。
思维具体：在思维中把各方面的本质规定综合起来，形成对事物整体的具体认识。
思维具体不是简单回到最初的感官印象，而是在认识基础上形成的、包含丰富规定性的整体认识。
# 4. 逻辑与历史相统一
这里的“历史”主要指客观事物自身的历史发展过程；
“逻辑”指理论思维对事物发展规律的反映。
逻辑要反映历史发展的本质和规律。
两者应当统一，但逻辑叙述不一定要机械照搬历史事件的先后顺序。理论可以舍去偶然细节，突出本质联系。
```

```shell
#🚗认识发展过程

认识运动的基本规律是：从实践到认识，再从认识到实践。

#🚗真理
真理是人们对客观事物及其规律的正确反映。
- 客观性：真理的内容是客观的，不以人的主观意志为转移。
- 绝对性：真理包含不依赖于人的主观意志的客观内容；人类能够正确认识客观世界，真理性认识可以不断积累。
- 相对性：在一定条件下，人们对客观世界的正确认识具有局限性，还需要继续发展和深化。
绝对性和相对性不是相互排斥的，而是辩证统一的。
```

```shell
#🚗商品经济和价值规律
# 商品经济
商品经济是以交换为目的而进行生产的经济形式。
自然经济主要是为了满足生产者自身及其共同体的需要而进行生产。
# 商品经济产生的两个基本条件
- 社会分工
- 生产资料和劳动产品属于不同的所有者(交换)
# 商品的二因素：使用价值和价值
商品是用来交换、能够满足人的某种需要的劳动产品。
- 使用价值(满足需要/自然属性)
- 价值(人类劳动/社会属性)
- 使用价值是价值的物质承担者
- 商品必须具有使用价值，才可能成为交换对象
- 使用价值和价值是商品的两个不同因素，不能混为一谈
# 具体劳动
具体劳动是指具有特定形式的劳动.
具体劳动的作用是：生产商品的使用价值。
# 抽象劳动
抽象劳动是指撇开各种具体劳动的有用形式后，无差别的一般人类劳动。
抽象劳动的作用是：形成商品的价值。
# 商品的价值量
由生产该商品的社会必要劳动时间决定的。
- 个别劳动时间
- 社会必要劳动时间(正常生产条件下)
# 价值规律
- 商品的价值量由生产商品的社会必要劳动时间决定
- 商品交换以价值量为基础，按照等价交换的原则进行(受供求影响)。
# 价值规律的表现形式
商品价格围绕价值上下波动。
- 供不应求(买方竞争/价格上涨)
- 供过于求(卖方竞争/价格下跌)
- 供求关系的变化会推动价格波动，但这不意味着价值规律失效。
# 价值规律的作用
- 自发调节生产资料和劳动力在社会各生产部门之间的分配。
- 自发刺激社会生产力的发展。
- 引起和促进商品生产者的分化。
价值规律既具有积极作用，也可能带来生产者之间的分化。
# 劳动生产率
劳动生产率是劳动者生产某种使用价值的效率，通常可以用单位时间内生产的产品数量来表示。
- 劳动强度：单位时间内劳动者的劳动紧张程度或劳动力耗费程度。
# 劳动生产率与单位商品价值量的关系
在其他条件不变的情况下，劳动生产率越高，单位商品的价值量越小；劳动生产率越低，单位商品的价值量越大。
# 为什么劳动生产率提高，价值总量通常不变
马克思主义政治经济学区分的是单位商品的价值量和一定时间内新创造的价值总量。
- 劳动生产率提高(单位商品价值量下降)
- 社会必要劳动时间增加(单位商品价值量上升)
- 劳动时间延长(在其他条件相同的情况下，创造的价值总量增加)
```

```shell
#🚗资本主义经济制度的本质
商品经济可以存在于不同社会形态，而资本主义经济制度具有特定的历史条件和阶级关系。
- 商品经济： 以交换为目的的生产经济形式。
- 资本主义经济制度： 以资本主义生产关系为基础的经济制度。
# 资本主义经济制度产生的基础
资本主义经济制度的形成，与劳动者和生产资料相分离、劳动力成为商品等条件密切相关。
# 劳动力
劳动力: 是人的劳动能力，即人的体力和脑力的总和。
劳动： 劳动力在生产过程中的实际运用。
# 劳动力成为商品的两个基本条件
- 劳动者具有人身自由
- 劳动者没有生产资料，也没有足够的生活资料，必须通过出卖劳动力来维持生活。
# 劳动力商品的价值与使用价值
劳动力的使用价值能够创造价值，而且可能创造出超过劳动力自身价值的价值。
- 劳动力商品的价值(生活资料价值/劳动者教育培训)
- 劳动力商品的使用价值(劳动者实际运用劳动力进行劳动，能够创造价值)
# 为什么劳动力能够成为商品
- 资本家需要劳动者的劳动来生产商品、创造价值
- 资本家购买的并不是劳动者这个人，而是劳动者在一定时间内提供的劳动力的使用权。
- 劳动力成为商品，意味着劳动者通过出卖劳动力获得生活资料。
# 劳动力商品的价值
劳动力商品的价值，是由生产和再生产劳动力所必需的生活资料的价值决定的。
- 维持劳动者本人生活所必需的生活资料
- 维持劳动者家庭及劳动力延续所必需的生活资料
- 教育和训练所支出的费用
工资: 在资本主义制度下，劳动力价值或价格的货币表现形式；实际工资还可能受到供求关系、劳资力量对比等因素影响。
# 劳动力商品的使用价值
一般商品的使用价值，是它能够满足某种需要的有用性。
- 劳动力的使用能够创造价值，而且能够创造出超过劳动力自身价值的价值。
- 资本家购买劳动力时支付的价值，与劳动力在使用过程中能够创造的新价值，并不是同一个量。
	劳动力价值
	剩余价值(超过劳动力自身价值)
# 在假设等价交换的情况下，资本主义生产仍然可能产生剩余价值
- 资本家按照劳动力的价值或价格购买劳动力。
- 劳动者在生产过程中创造的新价值可能超过劳动力自身的价值。
- 超过劳动力自身价值的部分形成剩余价值，并被资本家占有。
#🚗资本主义生产过程的二重性
资本主义生产过程是劳动过程和价值增殖过程的统一。
- 劳动过程(劳动者/劳动/使用价值)
- 价值增殖过程(劳动力/超过自身价值)
# 必要劳动时间与剩余劳动时间
- 必要劳动时间：再生产劳动力价值所需要的劳动时间。
- 剩余劳动时间：超过必要劳动时间、为资本家生产剩余价值的劳动时间。
# 绝对剩余价值与相对剩余价值
- 绝对剩余价值: 通过延长工作日，或者在必要劳动时间不变时增加剩余劳动时间，来增加剩余价值。
- 相对剩余价值: 在工作日长度不变的条件下，通过提高社会劳动生产率、降低劳动力价值，从而缩短必要劳动时间、相应增加剩余劳动时间。
#🚗资本的划分：不变资本与可变资本
- 不变资本(c): 用于购买生产资料的资本
	在生产过程中，生产资料的价值转移到新产品中，本身不创造新的价值。
- 可变资本(v): 用于购买劳动力的资本
	劳动力在生产过程中创造新价值，而新价值可以超过可变资本本身的价值。
- 剩余价值(m)的源泉是雇佣劳动者的剩余劳动，而不是机器本身。
# 资本的价值构成公式
- 商品价值: W = c + v + m
- 剩余价值率: m'= m/v * 100%
	m'= 剩余劳动时间/必要劳动时间 * 100%
#🚗剩余价值生产的两种基本方法
- 绝对剩余价值的生产
	延长工作日、必要劳动时间不变、剩余劳动时间增加。
- 相对剩余价值的生产
	缩短必要劳动时间,社会劳动生产率提高、劳动力价值降低
# 超额剩余价值
- 超额剩余价值，是指个别资本家由于提高企业劳动生产率，使商品的个别价值低于社会价值而获得的额外剩余价值。
- 相对剩余价值： 社会劳动生产率提高，使劳动力价值下降，必要劳动时间缩短。
- 个别生产率提高，可能获得超额剩余价值；社会生产率提高，可能形成相对剩余价值。
#🚗资本积累
资本积累，是指把剩余价值转化为资本，使扩大再生产得以进行。
- 简单再生产： 生产规模不变，剩余价值主要用于资本家个人消费。
- 扩大再生产： 把部分剩余价值转化为追加资本，扩大生产规模。
- 资本积累： 剩余价值转化为资本的过程，是扩大再生产的重要基础。
# 影响资本积累的因素
- 对劳动力的剥削程度(剩余价值率提高)
- 社会劳动生产率水平(劳动生产率提高)
- 所用资本和所费资本的差额(固定资本磨损)
- 预付资本的大小
# 资本有机构成
资本有机构成是由资本技术构成决定并反映技术构成变化的资本价值构成，通常用c:v表示
- 资本的技术构成(生产资料与劳动力之间的比例关系)
- 资本的价值构成(资本在价值上分为不变资本与可变资本的比例关系)
资本有机构成提高不等于任何情况下就业人数都会绝对减少；就业还会受到生产规模扩张、产业变化等因素影响
#🚗资本主义的基本矛盾
生产社会化与生产资料资本主义私人占有之间的矛盾。
- 生产社会化(社会化劳动)
- 生产资料资本主义私人占有
# 经济危机的可能性与根源
资本主义经济危机通常表现为商品大量滞销、生产下降、企业倒闭、失业增加等。
- 经济危机的根本原因：资本主义基本矛盾。
- 经济危机的直接原因: 常涉及生产与消费的矛盾、相对过剩等具体机制
#🚗资本循环
资本循环是指资本依次经过购买、生产和销售三个阶段，采取不同职能形式，实现价值增殖并回到原来出发点的运动过程。
- G: 货币资本
- W：商品，包括生产资料和劳动力。
- P: 生产过程
- W': 包含剩余价值的商品
- G': 收回的增殖后的货币资本
# 资本循环的三个阶段
- 购买阶段(货币资本/生产准备条件)
- 生产阶段(生产资料与劳动力/新商品)
- 销售阶段(新商品/增殖后的货币)
只有生产阶段才直接生产剩余价值；购买阶段为生产准备条件，销售阶段实现商品价值和剩余价值。
# 资本的三种职能形式
- 货币资本(购买生产资料和劳动力)
- 生产资本(生产商品和剩余价值)
- 商品资本(出售商品，实现价值增殖)
资本的三种职能形式不是三种互不相关的资本，而是同一资本在循环中采取的不同形式。
# 资本周转
资本周转速度影响资本在一定时期内能够完成多少次循环，也会影响预付资本的利用效率。
- 资本周转时间
	生产时间：资本处于生产领域的时间。
	流通时间：资本处于购买和销售等流通领域的时间。
- 周转时间越短，资本周转速度越快；周转时间越长，资本周转速度越慢。
#🚗固定资本与流动资本
- 固定资本
	以厂房、机器设备等劳动资料
	价值逐步转移
	多个生产周期发挥作用
- 流动资本
	一个生产周期全部转移
	劳动力使用形成新价值的生产资本
- 固定资本与流动资本的划分依据，是生产资本价值周转方式的不同。
# 不变资本、可变资本与固定资本、流动资本不是同一组分类
- 不变资本与可变资本：按资本在价值增殖中的不同作用划分。
- 固定资本与流动资本：按生产资本价值转移和周转方式划分。
# 预付资本的总周转
总周转次数 = 一年内各部分资本周转的价值总额/预付资本总额
#🚗社会资本再生产
社会总资本，是指相互联系、相互依存的个别资本的总和。
# 社会生产的两大部类
- 第Ⅰ部类：生产生产资料的部门
	需要用于扩大和维持社会生产
- 第Ⅱ部类：生产消费资料的部门
	需要满足劳动者及其他社会成员的生活消费。
- 两大部类的产品必须通过一定比例的交换，才能实现社会再生产的正常进行。
# 简单再生产与扩大再生产
- 简单再生产：生产规模保持不变，生产出来的剩余价值主要用于资本家个人消费。
- 扩大再生产：生产规模扩大，需要把一部分剩余价值转化为追加资本。
社会资本再生产理论研究的重点，是社会总产品如何在各部门之间实现价值补偿和实物补偿，从而使再生产能够继续进行。
#🚗社会资本再生产的实现条件
# 社会总产品与两大部类(经济用途)
社会总产品是社会各物质生产部门在一定时期内生产出来的全部物质产品。
- 第Ⅰ部类：生产生产资料
- 第Ⅱ部类：生产消费资料
# 简单再生产的基本实现条件
v: 可变资本
m: 剩余价值
c: 不变资本
Ⅰ(v+m)=Ⅱc
# 扩大再生产(生产规模不断扩大)
扩大再生产是指将一部分剩余价值转化为追加资本，使下一轮生产规模扩大。
扩大再生产不仅要补偿已经消耗的生产资料和劳动力，还要为追加资本提供相应的生产资料与消费资料。
社会总资本再生产能否顺利进行，取决于各部门之间是否保持必要的比例关系。生产出来的产品在实物上合适、在价值上能够实现，社会再生产才有条件继续进行。
# 两种补偿：价值补偿与实物补偿
- 价值补偿：商品通过销售实现价值，使资本家能够收回预付资本，并实现剩余价值。
- 实物补偿：生产过程中消耗的生产资料和消费资料，必须在实物形态上得到相应补充。
- 社会资本再生产需要同时考虑价值补偿和实物补偿，而不是只看产品有没有生产出来。
#🚗资本主义经济危机(相对过剩)
商品相对于有支付能力的需求出现了过剩。
# 经济危机的根本原因
- 生产越来越具有社会性。(相互依赖)
- 生产资料由资本家私人占有。(各自决策)
- 生产的社会化与生产资料私人占有之间的矛盾
# 为什么会出现生产过剩
- 资本家追求利润
- 扩大生产、提高竞争力
- 社会生产可能超过有支付能力的需求
- 商品相对过剩，经济危机爆发
# 经济危机的周期性
- 危机阶段：商品滞销、企业倒闭、失业增加。
- 萧条阶段：生产和商业活动处于低迷状态。
- 复苏阶段：投资和生产逐步恢复。
- 高涨阶段：生产进一步扩张，为下一轮危机积累条件。
```
