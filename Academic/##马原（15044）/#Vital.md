#🚗对立统一规律(矛盾规律)
# 统一/斗争性
- 矛盾的同一性(指矛盾双方相互依存、相互贯通的性质和趋势。)
- 矛盾的斗争性(指矛盾双方相互排斥、相互分离的性质和趋势。)
- 矛盾的同一性和斗争性是辩证统一的。同一性不能脱离斗争性而存在，斗争性也不能脱离同一性而存在。矛盾双方既相互依存，又相互排斥，共同推动事物的发展。
# 普遍/特殊
- 矛盾的普遍性(是指矛盾存在于一切事物的发展过程中，并贯穿每一事物发展过程的始终。)
- 矛盾的特殊性(是指不同事物的矛盾、同一事物不同发展阶段的矛盾，以及构成事物的不同矛盾和矛盾双方各有其特点。)
  + 不同事物的矛盾各有特点
  + 同一事物在不同发展阶段的矛盾各有特点
  + 同一事物中的不同矛盾，以及同一矛盾的双方，各有特点
- 矛盾的普遍性与特殊性相互区别。 
普遍性是共性，特殊性是个性，二者不能完全等同。
矛盾的普遍性与特殊性相互联结。 
普遍性寓于特殊性之中，并通过特殊性表现出来；特殊性也离不开普遍性。
矛盾的普遍性与特殊性在一定条件下可以相互转化。
# 普遍/特殊方法论意义
坚持具体问题具体分析。(分析和解决问题时，要从具体的时间、地点、条件出发，分析事物矛盾的特殊性，采取适合实际情况的方法。)
# 主要矛盾与次要矛盾
在复杂事物的发展过程中，存在着多种矛盾，
其中处于支配地位、对事物发展起决定作用的矛盾，就是主要矛盾。
其他处于从属地位、对事物发展不起决定作用的矛盾，是次要矛盾。
主要矛盾和次要矛盾的地位不是固定不变的，在一定条件下可以相互转化。
# 主要矛盾的意义
分析复杂事物时，要善于抓住主要矛盾。
方法论是：坚持重点论，着重把握主要矛盾。
但这不等于只管主要矛盾、完全不管其他矛盾。次要矛盾也会影响事物的发展。
# 矛盾的主要方面与次要方面
在一个矛盾的两个方面中，
处于支配地位、起主导作用的一方，就是矛盾的主要方面。
另一方则是矛盾的次要方面。
事物的性质主要是由取得支配地位的矛盾的主要方面决定的。
# 矛盾主要方面的意义
分析一个事物时，要分清矛盾双方谁处于主导地位，不能因为存在某些问题，就否定事物的整体性质。
方法论是：坚持两点论，全面分析矛盾双方，同时抓住主要方面。
# 两点论与重点论的统一
两点论：既看到主要矛盾，也看到次要矛盾；既看到矛盾的主要方面，也看到次要方面。
重点论：着重把握主要矛盾和矛盾的主要方面。
两者统一起来，就是：全面分析问题，同时抓住重点和主流。

#🚗否定之否定规律
辩证否定是事物的自我否定，是事物发展的环节，也是新旧事物联系的环节。
自我否定：事物的发展变化，源于其内部矛盾运动，不是简单地由外部力量任意决定。
发展的环节：通过否定，旧事物才能向新事物发展。
联系的环节：新事物不是凭空出现的，而是在旧事物的基础上产生。
# 辩证否定的两个重要特点
- 否定是发展的环节
	旧事物被新事物取代，是事物发展过程中的重要环节。
- 否定是联系的环节
	新事物是在旧事物的基础上产生的，因此会保留旧事物中合理的因素。
- 辩证否定的实质是“扬弃”。
	扬：保留旧事物中积极、合理的因素。
	弃：克服旧事物中过时、消极的因素。
事物的发展不是简单地直线前进，而是经历两次否定、三个阶段，表现为螺旋式上升或波浪式前进。
# 否定之否定规律的方法论意义
- 要对事物的发展前途充满信心。
	新事物具有符合客观规律、具有强大生命力和远大发展前途等特点。
- 要充分认识事物发展的曲折性。
	事物发展不是一帆风顺的，可能经历反复、挫折，但不能因此否定其发展的总体趋势。

#🚗三大规律
对立统一规律是唯物辩证法的实质和核心。

#🚗唯物辩证法的基本范畴
# 1. 原因与结果
原因：引起某种现象的现象。
结果：由原因引起的现象。
二者相互联系，在一定条件下还可以相互转化。
方法论：分析问题时要追究原因，也要关注行为可能带来的结果。
# 2. 必然性与偶然性
必然性：事物发展过程中确定不移的趋势。
偶然性：事物发展过程中不确定的趋势和表现。
必然性和偶然性相互联系，不能割裂。
偶然性不是完全没有原因，必然性也不意味着每个具体结果都能被简单预测。
# 3. 可能性与现实性
可能性：事物发展中潜在的趋势。
现实性：已经产生、实际存在的事物或状态。
可能性转化为现实性需要一定条件。
方法论：既要看到可能性，也要创造条件促使积极可能性转化为现实。
# 4. 内容与形式
内容：构成事物的一切要素及其内在联系。
形式：内容诸要素相互结合的结构和表现方式。
内容与形式相互依存，内容决定形式，形式对内容具有反作用。
# 5. 本质与现象
本质：事物的根本性质，以及组成事物的基本要素之间的内在联系。
现象：事物的外部联系和表面特征。
本质通过现象表现出来，现象是认识本质的向导，但现象不一定直接、完整地反映本质。
方法论：不能停留在表面现象，要通过分析研究把握事物本质。

#🚗唯物辩证法是认识世界和改造世界的根本方法
唯物辩证法不只是解释事物怎样发展，还指导我们怎样认识问题、分析问题和解决问题。
# 1. 归纳与演绎
归纳：从个别事实中概括出一般规律。
演绎：从一般原理推导出个别结论。
归纳由个别到一般，演绎由一般到个别。
# 2. 分析与综合
分析：把事物分解为不同部分、方面，分别研究。
综合：把对各部分的认识结合起来，形成对整体的认识。
分析是分开看，综合是合起来看。
# 3. 抽象与具体
感性具体：通过感官直接接触到的完整、具体事物。
思维抽象：从具体事物中抽取某些共同的、本质的属性。
思维具体：在思维中把各方面的本质规定综合起来，形成对事物整体的具体认识。
思维具体不是简单回到最初的感官印象，而是在认识基础上形成的、包含丰富规定性的整体认识。
# 4. 逻辑与历史相统一
这里的“历史”主要指客观事物自身的历史发展过程；
“逻辑”指理论思维对事物发展规律的反映。
逻辑要反映历史发展的本质和规律。
两者应当统一，但逻辑叙述不一定要机械照搬历史事件的先后顺序。理论可以舍去偶然细节，突出本质联系。

#🚗认识发展过程
实践 > 感性认识 > 理性认识 > 回到实践
认识运动的基本规律是：从实践到认识，再从认识到实践。
认识不是一次完成的。随着实践发展，人们会获得新的材料、发现原有认识的不足，并不断修正和深化认识。
# 认识发展条件
感性认识 > 理性认识
- 丰富的感性材料：有足够的观察和实践经验。
- 科学的思维方法：对材料进行比较、分析、综合、抽象和概括。
- 发挥认识的能动性：主动思考，透过现象把握本质。
# 为什么理性认识还必须回到实践
- 检验认识：看理论是否符合客观实际。
- 指导实践：运用认识改造客观世界，并在实践中发现新问题。
#🚗真理
真理是人们对客观事物及其规律的正确反映。
- 客观性：真理的内容是客观的，不以人的主观意志为转移。
- 绝对性：真理包含不依赖于人的主观意志的客观内容；人类能够正确认识客观世界，真理性认识可以不断积累。
- 相对性：在一定条件下，人们对客观世界的正确认识具有局限性，还需要继续发展和深化。
绝对性和相对性不是相互排斥的，而是辩证统一的。
# 实践是检验真理的唯一标准
判断一种认识是不是真理，关键在于它是否正确反映了客观事物及其规律。只有通过实践，把认识与客观实际联系起来，才能检验认识是否符合客观实际。
# 实践标准的确定性与不确定性
确定性：实践是检验真理的唯一标准，不存在能够最终取代实践的其他标准。
不确定性：具体实践及其检验往往受到历史条件限制，某次实践可能不能立即、充分地证明认识的全部内容。
#🚗价值
价值是客体对主体需要的满足关系。
# 真理与价值的辩证统一
- 真理是正确认识客观世界的基础。
- 价值体现认识和实践与主体需要的关系。
- 追求价值应当以尊重客观规律、遵循真理为前提。
- 实践活动往往既要追求正确认识，也要考虑实际目的和主体需要。
