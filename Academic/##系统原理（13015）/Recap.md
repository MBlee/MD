#### 加法器/算术逻辑部件

```shell
#🚗加法器
# 半加器(1位相加)
A + B = S,C (1+1=10)
S = A XOR B
C = A AND B
# 全加器(多位加法器/进位逐位传递)
A+B+C₁ = S,C (1+1+1=11)
S = A XOR B XOR C
C = AB + (A XOR B)C
```

```shell
#🚗ALU(算术逻辑部件)
输入: A,B,控制信号
输出: 运算结果,状态信息(标志位)
标志位: ZF(零),CF(进位),OF(溢出),SF(符号)
```
