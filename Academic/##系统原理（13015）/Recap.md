## 数据表示/运算

#### 数制和编码

```shell
#🚗进制转换
# R=>D
V(R)=Rn*R^n+...
# D=>R
整:除余,asc
浮:乘整,dsc...
# R1=>R2
0000=>000=>B
```

```shell
#🚗定点编码
# 补码
原码=>反码+1
# 原码|反码
01 0000000
01 1111111
# 移码
#🚗码值转换
(0-1)*2^(n-1)+...
```

#### 整数

```shell
(char/short/int/long)
(10000000=>-127)
#🚗unsigned
0∼2⁸−1
# signed
原码: -(2⁷-1)~2⁷-1, -127~127
补码: -2⁷~2⁷-1, -128~127
```

#### 实数

```shell
#🚗IEEE754单浮点(127/1023)
N=(-1)^S * (1.F) * 2^(E-127)
E(8)=e+127
F(23)=...
# 特例
- 阶码0..0
	尾数0..0(±0)
	不全0(非规格化数)
- 阶码0..1~11..0
 	尾数任意(正数)
- 阶码1..1
 	尾数0..0(±∞)
 	不全0(NaN)
# 非规格化数
N=(-1)^S * (0.F) * 2^(-126)
# C浮点(0.1误差)
float(32): 3.14f
double(64): 3.14
long double
```
