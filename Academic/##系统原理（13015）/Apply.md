#### 加法器/算术逻辑部件

```shell
#🚗加法器
# 半加器(1位相加)
A + B = S,C (1+1=10)
S = A XOR B
C = A AND B
# 全加器(多位加法器/进位逐位传递)
A+B+C₁ = S,C (1+1+1=11)
S = A XOR B XOR C
C = AB + (A XOR B)C
```

```shell
#🚗ALU(算术逻辑部件)
输入: A,B,控制信号
输出: 运算结果,状态信息(标志位)
标志位: ZF(零),CF(进位),OF(溢出),SF(符号)
```

#### 定点数乘除运算

```shell
#🚗乘法(移位/相加)
A*0=0
A*1=A
A*2^n=A左移n
# 原码乘法
符号+数值(移位+加法)
# 补码乘法
移位+加法
# Booth乘法
while Q₀Q-₁=01,10
	A±M
	Q₀Q-₁++
AQ
```

```shell
#🚗除法
# 补码除法
while A,Q<<
	A=A±M(同加异减)
	Q₀=0,1
A=A+M
```

## 程序的转换及机器级表示

```shell
#🚀转换过程(指令)
C程序(预处理/编译) 
	> 汇编指令(汇编-目标文件/链接-可执行文件) 
	> 机器代码
	> 处理器执行(加载/执行)
- 机器指令(二进制/指令集)
- 汇编指令(符号/mov,add,sub,eax)
- ISA(指令规则/接口)
- 微体系机构(硬件实现ISA)
- IA-32(x86-64/寄存器宽度)
# 指令系统设计风格
- CISC(x86)
- RISC(ARM/RISC-V)
# 转换核心
- 预处理(头/宏/条件编译)
- 编译(低代码/目标代码)
- 汇编(机器代码/目标文件)
- 链接(目标文件/库组合,处理符号引用/可执行文件)
```

```shell
#🚀IA-32数据
# 数据宽度
bit > Byte(8) 
	> Word(16) 
	> Doubleword(32)
    > Quadword(64)
# 整数
无符号: 0 ≤ x ≤ 2^n-1
有符号: -2^(n-1) ≤ x ≤ 2^(n-1)-1
# 浮点数(IEEE754)
32位: 1 + 8 + 23
64位: 1 + 11 + 52
```

```shell
#🚀IA-32寄存器组织
寄存器:EAX/EBX/ESI/EDI
EAX(32) > AX(16) > AH > AL
EIP: 指令指针
EFLAGS: 标志寄存器(CF/ZF/SF/OF)
段寄存器: CS/DS/SS/ES/FS/GS
#🚀寻址方式(操作数位置/数值)
- 立即数寻址
- 寄存器寻址
	mov eax, ebx
	add eax, ecx
- 直接内存寻址
	mov eax, [1000h]
- 寄存器间接寻址
	mov eax, [ebx]
- 基址加位移寻址
	mov eax, [ebx+8]
- 变址寻址和基址变址寻址
	mov eax, [ebx+esi*4+8]
```

```shell
#🚀机器指令格式
操作码 > 操作数信息 > 寻址方式信息 > 立即数或位移字段
# IA-32 指令长度(变长指令格式)
1条指令: 1~15字节
NOP: 1字节(空操作)
# 小端字节序
规定：多字节数据在内存中存放时，最低有效字节放在较低的内存地址。
12345678h : 78h 56h 34h 12h
操作码决定操作，寻址字段确定操作数
# ModR/M 和 SIB
```
