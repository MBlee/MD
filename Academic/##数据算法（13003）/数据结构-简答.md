#🚀简述递推法的思想
根据递推关系，能从已求得的问题规模为1，2，..，i-1的一系列解，构造出问题规模为i的解。求解规模为i的解时，有时可能仅需规模为1，2，..，i-1的系列解中的一部分，而不是全部。
# 简述算法的五个特性
①输入：有0或多个输入值。
②输出：有1或多个输出值。
③有穷性：一个算法必须在执行有穷步骤之后结束。
④确定性：算法的每一个步骤都必须有确切的含义。
⑤可行性：算法中要做的运算都是基本的、能够精确
# 设二维数组A[5][6]的每个元素占4个字节，已知数组首地址为1000,A共占多少个字节?分别按行和列优先存储时，A[2][5]的起始地址分别为多少
（1）数组A共占字节数：二维数组A[5][6]的元素总个数为“行数×列数”，即5×6=30个；每个元素占4个字节，因此总字节数为30×4=120字节。
（2）按行优先存储时A[2][5]的起始地址：行优先存储规则是“先存完第i行所有元素，再存第i+1行元素”，数组下标默认从0开始（若未说明，按计算机领域常用的0基下标计算）。首先计算A[2][5]之前的元素个数：第0行、第1行共2行，每行6个元素，共2×6=12个；第2行中A[2][0]到A[2][4]共5个元素，因此总个数为12+5=17个。每个元素占4字节，因此起始地址=首地址+17×4=1000+68=1068。
（3）按列优先存储时A[2][5]的起始地址：列优先存储规则是“先存完第j列所有元素，再存第j+1列元素”。首先计算A[2][5]之前的元素个数：第0列到第4列共5列，每列5个元素，共5×5=25个；第5列中A[0][5]到A[1][5]共2个元素，因此总个数为25+2=27个。每个元素占4字节，因此起始地址=首地址+27×4=1000+108=1108。

#🚀简述二叉树与度为2的树之间的差别
二叉树的子树有严格的左右之分，其次序不能任意颠倒，某个结点即使只有一棵子树，也区分是左子树还是右子树，而在度为2的树中，某个结点只有一棵子树时，是不区分左右的。除此之外，二叉树可以是空树，而度为2的树至少有一个度为2的结点，所以不能为空树。
# 简述二叉树先序遍历算法的过程
（1）访问根节点：首先访问当前二叉树的根节点，执行对根节点的操作（如输出节点值、记录节点信息等），这是先序遍历“先根”特性的核心步骤。
（2）递归遍历左子树：在访问完根节点后，以当前根节点的左子树为新的“当前二叉树”，重复先序遍历的过程（即再次执行“访问根节点→递归遍历左子树→递归遍历右子树”的步骤），直到左子树为空。
（3）递归遍历右子树：当当前根节点的左子树遍历完成后，以当前根节点的右子树为新的“当前二叉树”，再次重复先序遍历的过程，直到右子树为空。
（4）终止条件：当当前遍历的“二叉树”为空（即不存在根节点）时，停止该分支的遍历，返回上一层递归，继续执行未完成的遍历步骤，直至整个二叉树遍历结束。

#🚀含有n个顶点的连通图G的最小生成树有哪些性质
（1）边数固定：最小生成树恰好含有n-1条边，且通过这n-1条边可连接图中所有n个顶点，不存在冗余边（若边数多于n-1会出现环，少于n-1则无法连通所有顶点）。
（2）总权值最小：最小生成树是图中所有生成树里，边的权值之和最小的生成树，“最小”即体现在总权值的最优性上。
（3）连通性保障：最小生成树本身是连通图，且删除其中任意一条边后，都会变成非连通图（即树的“无环且边数最少”特性）。
（4）子树性质：若在最小生成树中任意选取一个子集的顶点，该子集在最小生成树中对应的边构成的子图，是该子集顶点所构成子图的最小生成树。
（5）边的选择特性：对于图中任意一条不在最小生成树上的边e，若将e加入最小生成树中，会形成一个唯一的环，且e是该环中权值最大的边（否则可替换环中权值更大的边，得到总权值更小的生成树，与“最小”矛盾）。

#🚀简述顺序查找方法的基本思想
顺序查找方法的基本思想是从顺序表头开始，用给定的目标与表中各记录的关键字值逐个进行比较。如果表中存在目标，则进行若干次比较后，一定能够找到目标。如果表中不存在目标，则比较到表尾也不会出现相等的情况。
# 列出五种构造哈希函数的方法
（1）直接定址法：直接取关键字或关键字的某个线性函数值作为哈希地址，例如哈希函数H(key) = key 或 H(key) = a×key + b（其中a、b为常数），该方法简单、均匀，适合关键字分布连续的情况。
（2）数字分析法：对关键字的各位数字进行分析，选取其中分布较均匀、重复性低的若干位数字作为哈希地址，适用于关键字位数较多且各位数字分布有规律的场景。
（3）平方取中法：先计算关键字的平方值，再取平方值中间的几位数字作为哈希地址。由于平方后中间 digits 与关键字的每一位都相关，能有效减少冲突，适合关键字各位分布不均匀的情况。
（4）折叠法：将关键字拆分成若干个位数相同的部分（最后一部分位数可不同），然后将这些部分进行叠加（相加或异或等），得到的结果作为哈希地址。根据叠加方式不同，可分为移位折叠和边界折叠，适合关键字位数较长的情况。
（5）除留余数法：取关键字除以一个不大于哈希表表长m的质数p后的余数作为哈希地址，即哈希函数H(key) = key mod p（p ≤ m且p为质数）。该方法计算简单、适用范围广，是实际应用中较常用的构造方法。
